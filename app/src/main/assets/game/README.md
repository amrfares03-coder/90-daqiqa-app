# 90 دقيقة — FINAL

لعبة تحديات كرة القدم عربية تعمل كتطبيق ويب متجاوب وPWA.

## تشغيل على الكمبيوتر
افتح `index.html` مباشرة. ولأفضل تجربة مع الصور وميزات PWA شغّل مجلد المشروع عبر خادم محلي.

## تشغيل على الهاتف
الأفضل رفع المجلد على استضافة HTTPS ثم فتح الرابط من الهاتف واختيار **إضافة إلى الشاشة الرئيسية / Install App** من المتصفح. الصور والشعارات الخارجية تحتاج اتصال إنترنت.

## رفع اللعبة على الإنترنت — Netlify
1. فك الضغط عن الملف.
2. ادخل إلى Netlify.
3. اختر **Add new project → Deploy manually**.
4. اسحب مجلد `90_Daqiqa_Final` إلى منطقة الرفع.
5. بعد النشر سيظهر رابط `netlify.app` يمكنك فتحه من الهاتف والكمبيوتر.

## رفعها على GitHub Pages
1. أنشئ Repository جديد على GitHub.
2. ارفع ملفات المشروع بحيث يكون `index.html` في جذر مصدر النشر.
3. من Settings → Pages اختر مصدر النشر.
4. افتح الرابط الذي يولده GitHub Pages.

## ملاحظة مهمة
اللعبة الحالية Front-end/PWA؛ حفظ التقدم والإحصائيات المحلية يتم على نفس الجهاز. اللعب الجماعي الموجود هو **محلي على جهاز واحد** (تمرير الجهاز بين اللاعبين). اللعب الحقيقي بين أجهزة مختلفة يحتاج خادمًا/قاعدة بيانات أو WebSocket في مرحلة لاحقة.
