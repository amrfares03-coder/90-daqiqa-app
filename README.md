# 90 دقيقة — Android APK (offline)

هذا مشروع Android WebView للعبة 90 دقيقة.

## البناء
افتح المشروع في Android Studio أو ارفعه إلى GitHub ثم شغّل GitHub Actions من تبويب Actions (workflow: Build APK).

## النسخة offline
تحتوي ملفات اللعبة داخل APK. الصور والشعارات التي تعتمد على مصادر خارجية قد تحتاج إنترنت.
